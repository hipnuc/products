# CAN 数据库

将 [J1939.dbc](J1939.dbc) 导入支持 DBC 的 CAN 分析工具，即可查看 HiPNUC
测量数据。Vector CANdb++ 可用于编辑数据库。

- Classic CAN、29 位标识符、8 字节负载，信号为小端序。
- 13 个报文标识符使用优先级 **3**、源地址 **0x08**。
  设备使用其他地址或优先级时，在工具或数据库副本中修改标识符。
- 不包含动态 CANFD83 报文；此类报文使用 Python 或 C 解码器。

数据库保留线上单位：加速度 **G**（1 G = 9.8 m/s²）、角速度 **deg/s**、
磁场 **µT**、角度 **度**。DBC 信号范围不代表产品精度或解算有效。

`Heading_CW` 与 `Euler_Yaw` 含义不同。日期可用时，`Year_Offset_2000` 为年份减
2000；年月日均为零时，其余时间字段表示按 24 小时循环的开机时间。
FF43 提供温度，其保留字节**不是气压**。GNSS 质量状态不代表 INS 位置有效，
不同 PGN 也不构成同步样本。

支持的报文、坐标配置和状态含义请参阅对应产品的 IMU/INS 手册。
