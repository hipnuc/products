# EtherCAT example (HI15)

[English](README.md) | [中文](README_zh.md)

`userexample` reads the PDO data of HI15 series devices through an IgH
EtherCAT master on a Linux PREEMPT-RT kernel. Build with CMake in this
directory after the master is installed. The two `.doc` files describe how
the real-time kernel and the IgH master were set up (Chinese).
